KeywordIQ 竞对采集设置

访问令牌不需要手动填：在浏览器里打开并登录 KeywordIQ 网页， 然后点下面的「从网页同步令牌」，插件会自己取。上报时若发现令牌缺失或已过期， 也会自动再同步一次。

从哪个来源读取登录态。本地开发必须单独填——网页在 8001、 API 在 8000，是两个来源；留空会去 API 地址读，而那里从来没写过令牌， 表现和「没登录」一模一样。生产环境网页与 API 同域，留空即可。

手动填写令牌（兜底，通常用不到）

自动同步依赖标签页与浏览器权限，真机上总有失败的可能。这条路留着，是为了 那种时候插件不至于完全不可用。令牌在已登录的网页上按 F12 → Application → Local Storage → keywordiq_token。
