## Why

机会档案能回答「需求在不在、头部稳不稳、专利查了没有」，但回答不了「按能卖的价格还有没有利润、采购价最多能接受多少」。档案里「供应成本」「售价」两个缺口只能靠人工证据填一段文字，金额无法复算。核价引擎（change `add-pricing-calculation`，已上线）已经能按费用规则正算、反推售价与采购价上限，并保存不可变的版本快照，但它和档案互不相通：核价单按创建人私有，团队在档案里看不到测算结论，签决定时也没有留下当时的测算依据。

2026-11-12 用户要求「商业可行性专家，继续工作」，范围由实现方判断。#171 的方向是「Agent 组织信息、调用统一计算、解释结果；金额不能由语言模型生成」，本变更按这个方向只做第一步：把核价单接到档案上。

## What Changes

- 档案可以关联核价单：只能关联自己名下的核价单；一张核价单至多挂一个档案。
- 档案向团队展示关联核价单的**测算摘要**：每个市场的选定方案（或尚未选定时的推荐方案）、售价、预计单件利润、利润率、保本价、采购价上限与结果状态（如「费用规则未启用」「待补资料」）。摘要只取核价单**已保存版本**里引擎算出的值，不在档案里另算。核价输入、费用明细与版本历史仍只有创建人可见。规则已更新时提示重新核价。
- 从档案「发起核价」：以档案标题为产品名、档案站点为市场建一张草稿核价单并自动关联，然后进入「定价核算 › 快速核价」继续填写。
- 签署决定时固化当时的测算状态，与专利状态并列。
- 追问的证据里加入测算摘要；提示词要求金额只能原样引用核价结果，不得自行计算或换算。
- 专家名片「商业可行性」改为已接入并指向机会档案。

## Capabilities

### Modified Capabilities
- `opportunity-dossier`（由尚未归档的 `add-opportunity-dossier` 新增）：新增「档案关联核价单并向团队展示测算摘要」；决定与追问的要求补充测算状态。

## Impact

- 数据库：`pricing_sheet` 加可空列 `dossier_id`（`ON DELETE SET NULL`）与部分索引；`opp_dossier_decision` 加可空列 `pricing_status`。一条迁移，不动事实表。
- 后端：`dossier_service` 增加核价摘要、关联/解除、从档案建草稿；`dossier_ask` 输入加摘要；端点挂 `opportunity:view`，从档案建核价单另要求 `pricing:view`。
- 前端：档案详情新增「商业可行性」面板；核价页不改。
- 不产生外部调用。生产费用规则仍是草稿、汇率未录：规则启用前，摘要会如实显示「费用规则未启用」，不显示金额。
