# 归档 V1 并将 V2 主线切到 main

## 原因

KeywordIQ 当前的默认分支仍指向 V1，V2 的开发、CI 和发布位于 `v2`。将主仓 V2 设为
默认主线，同时保留 V1 历史和运行环境。

## 变更内容

- 主仓分支按 `main → v1`、`v2 → main` 切换，保留两条提交历史。
- 将 V2 的 PR、范围 CI、发布门禁和 ECS 手动发布迁到 `main`，发布入口显示为
  **Deploy Main to ECS**。保留手动触发、精确 SHA 和 V1/V2 隔离。
- 延续现有 Claude 工作流，更新仓库规则与运维指引。
- 切换期间冻结飞书发布。恢复飞书发布时另行对齐分支、同次 push CI 证据和发布入口。

## 影响

涉及 `v2-ecs-cd`、`ops-release-control`、主仓设置、本地 worktree 及 ECS V2 的 Git 检出。
备用仓退出交付。分支切换没有数据库迁移；首发需要单独授权。关联 #208。
