## ADDED Requirements

### Requirement: 批次展示查询统计状态

导入批次查询接口 SHALL 返回每个批次的查询统计状态。上传屏的最近导入看板与导入历史屏 SHALL 在已完成批次的查询统计为待更新或失败时，在状态下方显示说明，提示查询可能暂时较慢，失败时提示联系管理员；就绪或不适用时 MUST NOT 显示额外说明。

#### Scenario: 待更新批次显示提示

- **WHEN** 某已完成批次的查询统计状态为待更新
- **THEN** 两个屏在「已完成」标签下显示查询统计待更新的说明

#### Scenario: 失败批次显示提示

- **WHEN** 某已完成批次的查询统计状态为失败
- **THEN** 两个屏在「已完成」标签下显示查询统计更新失败、请联系管理员的说明

#### Scenario: 就绪与旧批次不打扰

- **WHEN** 批次查询统计状态为就绪，或为迁移前的旧批次（不适用）
- **THEN** 「已完成」标签下不显示查询统计相关说明
