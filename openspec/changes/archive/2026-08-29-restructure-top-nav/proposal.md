# 重构顶栏菜单：拆掉「工具箱」这个按排除法命名的容器

## Why

`工具箱` 的定义是「不属于选品主线的其他东西」——名字说的是**它不是什么**，不是它装了什么。
这种容器只会越装越杂，而且已经杂了：

| 二级屏 | 读什么数据 | 什么时候用 |
|---|---|---|
| 持续增长市场 | `fact_daily`（ABA 搜索词） | 选品时找上升词 |
| 我的词库 | `fact_daily/weekly` + `fact_dropped` | 选品后盯排名 |
| 外观专利 | 专利库（**不存在**） | 定型前查侵权风险 |
| 全球商标库 | 商标库（**不存在**） | 定型前查侵权风险 |

前两个与分析查询屏是同一批事实表（`fact_metric_columns` 本来就两屏共用），而且**词库的
唯一入库入口就在分析查询屏**；后两个是另一个数据域、另一个使用时刻，且今天连数据源都没有。
四者唯一的共同点是「都不是主屏」。

上一个变更（竞对监控）**没有**放进工具箱，那其实就是这个容器已经没有原则的第一个证据：
新东西来了，判断标准不是「它属于工具箱吗」，而是「它像不像已经在里面的那些」，
而后者没有答案。

## What Changes

**顶栏从四项变五项，每一项按主题命名：**

```
ABA数据选品  /analysis    （单页，全宽）              analysis:view
关键词工具    /keyword     ├ 持续增长市场 ├ 我的词库    keyword:view（由 toolbox:view 改名）
竞对监控      /competitor  （单页）                    competitor:view
侵权查询      /ip          ├ 外观专利 ├ 全球商标库      不设权限点，只要求已登录
数据上传      /upload      ├ 上传文件 ├ 导入历史        upload:import
```

- **`工具箱` 这个名字消失**，剩下的两屏改名 `关键词工具`——它们真有共同主题。
- **外观专利 / 全球商标库拆成一级 `侵权查询`**。名字取使用场景（卖家嘴里说的是「查侵权」），
  不取数据域（「知识产权」）。
- **权限点 `toolbox:view` 改名 `keyword:view`**，只覆盖增长榜与词库两屏。
- **`侵权查询` 不设权限点**：它没有后端端点，按 `permissions.py` 自己写着的理由，
  没有端点可挂的权限点就是「勾了也不生效」的复选框。等它有端点时再加，那时是加法。
- 后端 API 前缀与 Python 包同步改名（`/api/toolbox/*` → `/api/keyword/*`，
  `app/table/toolbox/` → `app/table/keyword/`）。这一组任务可单独砍掉，见 design 决策 5。

**明确不做的两件事：**

- **不把关键词工具并进 `ABA数据选品`**。数据域上那才是最干净的分组，但 `app.tsx` 是
  `layout: 'mix'` + `splitMenus`，顶层节点一旦有子项就长出左侧栏。分析查询屏是全产品最宽的
  表，付不起这约 208px。见 design 决策 2。
- **不给侵权查询接数据源**。它仍是占位屏，仍明说「数据源尚未接入」、仍不发请求。

## Impact

- **导入路径完全不受影响**：日报与周报的导入、分区、保留清理一行都不改。
- **没有人的可见范围发生变化**：`toolbox:view` 今天授予 admin/operator/analyst 全部三个
  内置角色，改名是 `permission.code` 的一行 UPDATE，`role_permission` 按 `permission.id`
  关联、不受影响。
- **查询性能不受影响**：不改任何 SQL、索引与连接池配置。
- 受影响能力：`toolbox-navigation`（退休）、新增 `top-nav-structure`；
  `growth-market-list`、`keyword-library`、`competitor-storefront-watch` 三处权限码/路径引用同步。
