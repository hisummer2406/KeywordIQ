## Why

Refs #143。#141 把“首次入榜”改为查询时对 `dim_keyword` 永久记录的派生后，生产库存量词全是「未知」，上线后所有历史日期显示“无法判断”。原 spec 规定回填永不产出「导入创建」，只能等新导入逐期累积。V2 于 2026-09-19 上线，事实表尚未发生保留清理，库内保存着全部导入历史，可以按证据重放出与逐期导入完全一致的结果。

## What Changes

- 回填在**证据完整性校验通过**时可按期次重放：站点最早一期（B0）的词记「最早可观测」，之后才第一次出现的词记「导入创建」；校验不通过拒绝执行。
- 回填须保存原状态以便精确撤销。
- 「站点监测起点」「导入创建」的定义同步放宽，常规回填仍不产出「导入创建」。
- README 运行环境改为实际部署（PostgreSQL 与应用同机容器，非 RDS 2C4G）。

## Impact

- spec：`keyword-first-seen`（MODIFIED 三条 Requirement）。
- 代码：`scripts/backfill_first_seen.py` 增加证据重放、完整性校验、回滚表与撤销；导入与回填共用 `importer.first_seen_advance_sql` 比较键（导入行为不变）。
- 数据：2026-10-22 已在生产库用手工 SQL 完成一次重放，结果记录见 tasks。
