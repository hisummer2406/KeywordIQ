## ADDED Requirements

### Requirement: 长查询与等待的提示有界且去重

分析查询的长耗时、排队等待、超时和查询统计更新失败 SHALL 产生可定位的诊断记录，同一类提示在时间窗内 MUST 去重，总量 MUST 有界，MUST NOT 因拥堵而放大日志量。诊断 MUST 区分日报与周报，并保留 `stage_ms` 阶段耗时，使重采可以分别统计两种视图。诊断与错误响应 MUST NOT 泄漏 SQL 与内部细节。

#### Scenario: 拥堵时同类提示被去重
- **WHEN** 短时间内大量请求触发同一类排队超时
- **THEN** 日志中该类提示按窗口聚合，不逐条刷屏

#### Scenario: 诊断可区分日报与周报
- **WHEN** 统计一段时间内的分析查询耗时
- **THEN** 可以按日报与周报分别得到分布
