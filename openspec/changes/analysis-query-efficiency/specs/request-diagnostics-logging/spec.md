## ADDED Requirements

### Requirement: 分析查询诊断可分视图统计且提示有界去重

`POST /api/analysis/search` 的请求摘要 SHALL 带视图（日报/周报）与结果键指纹，使耗时分布可按视图分别统计，重复率与潜在缓存命中率可从日志估算。结果键指纹 MUST 为不可逆哈希，MUST NOT 含原始筛选内容或用户标识以外的私有数据。排队超时、语句或请求超时、取消与查询统计更新失败的提示 SHALL 按类型、站点与视图在时间窗内去重，窗口内只记首条并累计次数，日志总量 MUST 有界，MUST NOT 因拥堵而放大日志量。诊断与错误响应 MUST NOT 泄漏 SQL 与内部细节。

#### Scenario: 可按视图统计耗时
- **WHEN** 统计一段时间内的分析查询耗时
- **THEN** 可以按日报与周报分别得到分布

#### Scenario: 可估算重复率
- **WHEN** 按结果键指纹与时间窗汇总请求摘要
- **THEN** 可以得到并发重复与短时间内重复查询的比例

#### Scenario: 拥堵时同类提示被去重
- **WHEN** 短时间内大量请求触发同一类排队超时
- **THEN** 日志中该类提示按窗口聚合并记录次数，不逐条刷屏
