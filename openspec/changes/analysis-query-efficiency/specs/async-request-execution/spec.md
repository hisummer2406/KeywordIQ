## ADDED Requirements

### Requirement: 分析查询拥堵时轻量请求保持在预算内

分析查询占满并发位或出现排队时，鉴权（`/api/auth/me`）、作用域（`/api/analysis/scope`）与期次选择这类轻量请求 SHALL 仍在约定预算内响应（目标 p99 ≤ 1 s，待部署后重采确认）。并发闸的容量或连接池分配的调整 MUST 有测量依据，MUST NOT 以单纯增加连接数代替。

#### Scenario: 分析查询拥堵时轻量接口仍及时返回
- **WHEN** 同一 worker 内分析查询并发已满并有排队
- **THEN** 轻量接口的响应时间仍在预算内，不因等待连接而超时

#### Scenario: 调整容量需有测量依据
- **WHEN** 变更并发闸上限或连接池容量
- **THEN** 变更说明引用对应的测量结果，并保持全局连接上限满足既有算式
