# 将 Agent 常驻约定压缩到 800 行以内

## Why

Refs #142。原 CLAUDE.md 1692 行混合跨域红线、领域细则、事故经过与重复配置；所有任务全量读取成本过高。
用户在评审后明确批准主文件精简、按域必读和逐段去向核对，并要求执行；此前已批准的维护纪律与部署授权需保留。

## What Changes

- 主文件压到 800 行以内，保留数据、权限、生产、并行会话与验证红线，禁止靠拼长行达标。
- 领域细则分入版本化 openspec/guides/，每个领域有明确读取触发；不要求所有任务全部加载。
- 逐段记录迁移/压缩/纠错的去向，去掉完整环境模板复制和失效容量结论。
- AGENTS 仅更新入口与篇幅说明，Codex 审核规则不变；OpenSpec 配置用入口替代旧环境参数。

## Impact

仅文档与 OpenSpec 上下文，两种报表的代码/数据/数据库均不变；无迁移、无发布、无新工具。
保留原有未提交的部署授权与维护纪律；不关闭 #142，不把文档覆盖核对声称为实现/生产审计。
