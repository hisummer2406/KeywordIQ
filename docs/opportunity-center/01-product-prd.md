# 产品 PRD：机会中心——多专家 Agent 工作台

**状态：** 待评审草案  
**范围：** Amazon 需求判断与增长监控；不包含自动经营或采购执行。

## 1. 背景与目标

**事实。** KeywordIQ 当前以 Amazon 日/周搜索词报表、关键词/类目/ASIN 筛选、排名及份额趋势为核心。#76 已定义机会中心入口与独立权限；#54 已定义由确定性 Signal 驱动的主动式需求情报方向。

**问题。** 现有流程停留在“导入 → 查询 → 筛选 → 查看结果”。用户发现变化后，没有统一位置组织验证、风险、决策、审批和结果回查。

**目标。** 让用户将输入或 Signal 转化为一个可协作、可审计、可推进的机会档案，形成“发现 → 验证 → 风险 → 决策 → 推进 → 复盘”的闭环。

## 2. 用户与工作任务

| 用户 | 要完成的工作 |
|---|---|
| 运营专员 | 发起研究、补充证据、执行获批内部验证、回填进展 |
| 业务负责人 | 比较机会、处理风险取舍、批准/退回/否决验证计划 |
| 管理员 | 管理成员、数据授权、审批策略、审计与试用范围 |

核心场景：

1. 用户输入关键词、ASIN、链接、图片或自然语言目标，发起机会研究。
2. 系统从确定性 Signal/榜单创建待处理机会，用户决定深入分析或忽略。
3. 负责人查看证据、反证和风险缺口，决定推进、补证、观察或否决。

## 3. 概念与信息架构

| 对象 | 定义 |
|---|---|
| Signal | 由确定性规则或用户输入产生、值得检查的变化；不是结论。 |
| 机会 | 围绕对象、市场、时间窗和目标组织的可验证业务假设。 |
| 机会档案 | 问题、证据、专家任务、风险、决策、审批和复盘的唯一载体。 |
| 证据包 | 每条结论关联的来源、参数、时间、原始摘要与质量说明。 |
| 待批准动作 | Agent 生成、尚未执行的内部任务或草稿。 |

信息架构：

- **机会中心 / 收件箱**：待处理 Signal、我创建的机会、待我审批、观察中；使用 Tab/筛选，不增加左侧二级菜单。
- **机会档案**：总览、证据、专家任务、风险、验证计划、决策/复盘、审计。
- **全局发起器**：输入后创建或关联档案，不产生孤立聊天会话。

## 4. 三条关键流程

### 4.1 用户主动发起

输入 → 标准化对象/市场确认 → 主理 Agent 仅澄清必要约束 → 创建机会档案与研究计划 → 专家取证 → 负责人决策。

图片可作为输入和待验证假设来源，但不等于商品属性、权属、供应可行性或侵权结论。

### 4.2 Signal 驱动

质量通过的导入/指标计算 → 确定性规则生成 Signal → 去重/冷却 → 收件箱卡片 → 用户创建或合并至机会 → 进入验证流程。

数据缺期、重复、错期或来源过期时，只生成“数据异常/阻塞”，不得生成机会或风险结论。

### 4.3 决策与推进

证据齐备或记录缺口 → 风险关卡 → “推进 / 补证 / 观察 / 否决”建议 → 有权人审批 → 创建内部验证任务、shortlist、询盘草稿、素材 brief 或导出需求包 → 人工外部执行与回填 → 基线回查。

## 5. 体验原则

1. 工作台优先，聊天次要；用户进入的是一个可推进的对象，不是空白对话框。
2. 证据、结论、建议分开显示；每条结论均能回到来源、时间、口径和冲突。
3. 明确展示“未接入、无权限、授权过期、低量、缺期、未核查”；不得以 0、分数或话术伪装完成。
4. 子任务显示目的、当前状态、已使用数据和阻塞原因；用户可编辑问题、补充约束或退回计划。
5. 默认只展示当前决策所需摘要，支持展开证据、版本和审计。

## 6. 权限与不可突破的边界

最低权限：`opportunity:view`、`opportunity:create`、`opportunity:edit`、`opportunity:approve`、`opportunity:manage`、`opportunity:audit`。后端必须校验，菜单隐藏不能代替鉴权。

V0/V1 永久禁止 Agent 自动询盘、采购、谈判、付款、调价、投广告、修改 Listing、上下架。允许生成的 shortlist、询盘草稿、验证任务、素材 brief 和导出需求包必须标示“待批准”，并记录目标、证据、创建者、审批人和理由。

## 7. 分期与非目标

| 阶段 | 用户可见能力 |
|---|---|
| V0 | 入口/权限/诚实空状态；人工创建机会；关键词/ASIN/链接输入；档案、证据元数据、确定性 Signal 引用、审批、内部验证任务、采纳/忽略与基线。 |
| V1 | 受控主理/专家协作；围绕档案对话；#7 与 #38 接入后的证据；已授权 #78 数据；人工确认式偏好候选。 |
| 后续 | 获授权连接器、更多 Signal、供应可行性资料整合、跨源冲突规则与复盘排序优化。 |

非目标：泛化聊天、自动供应商触达/交易、虚构数据源或指标、将风险提示当法律意见、将效果回查看作因果证明。

## 8. 产品验收

- [ ] 授权用户可创建、查看、协作和推进机会；未授权用户前后端均不可访问。
- [ ] 机会档案展示标准化对象、市场、来源、问题、证据、未知项和下一步。
- [ ] 至少三类已验证的确定性 Signal 可创建/关联机会，且可回溯规则版本、输入批次和基线。
- [ ] 每个 Agent 结论都有来源、时间范围、质量/冲突和反证条件；证据不足时只进入补证或阻塞状态。
- [ ] 审批、退回、否决和内部任务全程审计；任何自动外部写动作被拒绝。
