# 实施分期、依赖与验收

## 1. 推荐拆分顺序

1. **基础隔离与权限**：#13 的租户决策，#76 的机会入口和后端权限。
2. **可信事实与 Signal**：导入质量门槛、#7 指标字典/预计算、Signal 去重和单次调度。
3. **机会工作台 V0**：档案、证据快照、任务状态机、审批、审计、内部验证任务与基线。
4. **受控 Agent 运行时**：语义层、工具契约、主理/专家任务、trace 与 Golden Cases。
5. **特定证据扩展**：#38 ASIN 反查，#78 经授权的 Google Trends，#24/#25 经验证的风险数据源。
6. **V1 个性化与复盘**：部分阈值/通知、人工确认式偏好候选和结果排序优化。

## 2. V0 验收

- [ ] `opportunity:view` 独立鉴权；前端可见性和后端访问控制一致。
- [ ] 用户可由自然语言、关键词、ASIN 或链接创建档案并修改标准化对象。
- [ ] 档案完整显示问题、市场、证据、未知项、任务、阶段与下一步。
- [ ] 至少三类质量通过的确定性 Signal 可追溯至规则版本、输入批次和基线。
- [ ] 结论没有证据时只能阻塞/补证；不能产生正面或负面业务判断。
- [ ] 每个“建议推进”候选均有独立 Checker 的尝试推翻记录；豁免必须由负责人明确记录理由。
- [ ] 审批、退回和否决有理由及审计；外部写动作统一拒绝。
- [ ] 工具风险级别被记录并执行：`auto` 无阻塞、`hard-gate` 等待指定审批、`block` 拒绝。
- [ ] 指标、规则、模板和工具契约均有版本、所有者、最近复核与有效期；失效资产可反查受影响结论。
- [ ] 已注册指标通过声明的数学关系或数据约束校验；失败版本不能进入 Signal/Agent 工具。
- [ ] 所有被采纳建议记录基线与观察窗口；回查结果区分改善、无明显变化、恶化和数据不可用。

## 3. 外部连接器启用验收

- [ ] 每个连接器有书面授权、适用市场、凭证主体、成本、限流、缓存/展示/删除策略和失败降级。
- [ ] #78 的 Google 相对热度与 Amazon 指标独立展示，并显示查询、地区、时间和限制。
- [ ] #38 的 ASIN 证据覆盖约定的 Top 1/2/3 槽位并显示热窗口。
- [ ] #24/#25 的风险结果显示覆盖范围、来源、更新时间和未覆盖项；未接入时明确为未核查。
