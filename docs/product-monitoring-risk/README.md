# 产品库、产品监测与风险核查

状态：待评审。调研日期：2026-09-05。

本目录集中保存这组需求的调研、功能设计和后续评审材料。

## 阅读入口

[完整功能设计](01-functional-design.md)包括：

- 原始产品库、侵权审核表及既有 PRD 的需求梳理。
- 卖家精灵产品库、监控、外观专利与商标查询的功能对照。
- 页面组织、产品档案、监测事件、分市场审核和历史案例复用。
- 旧表迁移、数据与权限边界、交付顺序和验收条件。

## 核心设计

产品档案保存研究对象，产品监测记录变化，风险案例保存历史证据，审核单记录针对具体产品版本和市场的人工结论。

内部案例与人工流程可先落地；文字商标和外观检索仍按原 PRD 保留为上线必做，数据接口和授权需要验证。

## 与机会中心的关系

[机会中心需求](../opportunity-center/00-decision-summary.md)负责机会研究、推进与复盘。本模块提供产品对象、监测事件和审核证据；双方引用同一份结果，不分别维护重复的业务决策。
