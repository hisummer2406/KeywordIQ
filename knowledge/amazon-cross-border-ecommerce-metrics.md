# 亚马逊跨境电商核心指标指南

做亚马逊跨境电商，核心不是孤立地看一堆数字，而是用指标持续回答四个问题：

1. **市场**：需求是否真实、规模是否足够？
2. **流量**：商品是否获得了有效曝光和点击？
3. **转化**：进入详情页的消费者是否愿意购买？
4. **利润**：扣除全部成本后，增长是否仍然健康？

围绕这四个问题，实际经营中通常需要同时关注市场、竞争、流量、转化、广告、销售、
利润和库存八类指标。

> 本文是业务知识指南，不是 KeywordIQ 当前功能或数据字段清单。部分指标来自 Amazon
> Seller Central、Amazon Ads、成本台账或第三方调研，是否已接入产品应以当前代码和接口为准。

## 一、八类核心指标

| 类别 | 重点指标 | 主要回答的问题 |
|---|---|---|
| 市场 | 搜索量、关键词趋势、类目容量、Top 10 / Top 100 销量 | 市场有多大，需求是在增长还是衰退？ |
| 竞争 | 竞品数量、Review 数、评分、品牌集中度、价格带 | 新商品能否进入，进入成本有多高？ |
| 流量 | Impressions、Sessions、CTR、关键词排名 | 商品有没有被看见，曝光能否转化为访问？ |
| 转化 | CVR、Add to Cart、Buy Box 率 | 访问商品页的人为什么买或不买？ |
| 广告 | CPC、ACoS、TACoS、ROAS | 广告获取订单的效率和可持续性如何？ |
| 销售 | Orders、Units、Sales、客单价 | 实际卖出了多少，销售结构是否健康？ |
| 利润 | 毛利率、净利率、FBA 费、佣金、物流费、广告费 | 销量增长最终有没有形成利润？ |
| 库存 | 库存周转天数、IPI、缺货率、库龄 | 是否会断货、积压或产生长期仓储成本？ |

### 1. 市场指标

市场指标用于确认需求是否存在，以及需求规模和趋势是否值得投入。

- **搜索量与关键词趋势**：观察消费者主动需求及其季节性、增长或衰退趋势。
- **类目容量**：衡量目标类目可承载的总体销售规模。
- **Top 10 / Top 100 销量**：观察头部与腰部商品的销量分布，避免只用单个爆款代表整个市场。

### 2. 竞争指标

竞争指标用于估算进入门槛，而不是简单地把“竞品多”判定为不能做。

- **竞品数量**：判断供给拥挤程度，但需要结合有效需求一起看。
- **Review 数与评分**：衡量消费者信任门槛和现有商品满意度。
- **品牌集中度**：判断销量是否长期被少数品牌占据。
- **价格带**：确认主流成交区间，并识别低价竞争或溢价空间。

### 3. 流量指标

- **Impressions（曝光量）**：商品或广告被展示的次数。
- **Sessions（访问次数）**：消费者进入商品详情页的访问量。
- **CTR（点击率）**：`Clicks / Impressions`，反映主图、标题、价格和广告位的吸引力。
- **关键词排名**：反映商品在具体搜索词下获得自然流量的能力。

### 4. 转化指标

- **CVR（转化率）**：常用口径为 `Orders / Sessions`，使用时应注明具体报表口径。
- **Add to Cart（加购）**：帮助判断消费者是否产生购买意向。
- **Buy Box 率**：衡量商品获得主要购买入口的比例，对跟卖或多卖家 Listing 尤其重要。

### 5. 广告指标

- **CPC（单次点击成本）**：`Ad Spend / Clicks`。
- **ACoS（广告销售成本比）**：`Ad Spend / Ad Sales`。
- **TACoS（总广告销售成本比）**：`Ad Spend / Total Sales`，可用于观察广告对整体销售的依赖程度。
- **ROAS（广告投入回报）**：`Ad Sales / Ad Spend`，与 ACoS 互为倒数口径。

广告指标必须与毛利空间一起判断。ACoS 较低不一定代表利润健康，ACoS 较高也可能处于新品
获取排名和积累转化数据的阶段。

### 6. 销售指标

- **Orders（订单数）**与 **Units（销量）**：区分一次订单购买多件的情况。
- **Sales（销售额）**：需要区分商品销售额、广告归因销售额和退款后的净销售额。
- **客单价**：常用口径为 `Sales / Orders`。

### 7. 利润指标

- **毛利率**：需明确是否已扣除采购、头程、佣金、FBA 和广告等成本。
- **净利率**：在毛利基础上继续扣除运营、退货、仓储、促销和其他期间费用。
- **费用结构**：重点拆分采购成本、FBA 费、平台佣金、物流费、广告费和退货损失。

所有利润指标都应固定计算口径和币种，避免把不同成本覆盖范围的“利润率”直接比较。

### 8. 库存指标

- **库存周转天数**：按当前销售速度估算库存可支撑的天数。
- **IPI（库存绩效指标）**：Amazon 对库存管理效率的综合评价。
- **缺货率**：衡量有需求但无可售库存的频率或时长。
- **库龄**：观察库存存放时长及长期仓储费、折价清仓风险。

库存需要与销量趋势、补货周期和安全库存联动判断：库存过少会损失排名和销售，库存过多会
占用现金并增加仓储成本。

## 二、选品重点关注的六个指标

选品阶段可以把复杂指标收敛为一条判断链：

**搜索量 → 市场销量 → 竞争强度 → 售价 → 毛利率 → Review 门槛**

| 指标 | 判断重点 | 常见误区 |
|---|---|---|
| 搜索量 | 核心词及长尾词是否有持续、可验证的需求 | 只看单月高点，不看趋势和季节性 |
| 市场销量 | 需求是否转化为真实购买，销量是否只集中在少数头部商品 | 用搜索热度直接代替成交规模 |
| 竞争强度 | 竞品数量、品牌集中度、广告成本、Review 与评分门槛 | 只用竞品数量判断竞争 |
| 售价 | 主流成交价格带能否覆盖成本，并保留促销空间 | 只看标价，不看优惠后的实际成交价 |
| 毛利率 | 扣除采购、物流、平台履约和获客成本后是否仍有安全垫 | 漏算广告、退货、仓储或汇率波动 |
